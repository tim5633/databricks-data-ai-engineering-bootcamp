| Day | Official course / topic focus | Lab / proof |
|---|---|---|
| 57 | [Databricks Performance Optimization](https://www.databricks.com/learn/training/home): query profiles, skew | Reproduce one slow query |
| 58 | Spark advanced physical plans and adaptive optimizations | Record before/after benchmark |
| 59 | Lakeflow Streaming and state / checkpoint failure | Recover after forced interruption |
| 60 | Lakeflow CDC and schema evolution | Handle duplicates and late events |
| 61 | Unity Catalog security and audit evidence | Verify row/column policies |
| 62 | End-to-end production pipeline (4h) | Release-ready deployment |
| 63 | Official DE Professional [exam guide](https://www.databricks.com/learn/training/certification) | Domain coverage audit |
| 64–69 | Advanced job orchestration, reliability, CI/CD, structured-streaming operations | Failure injection, rollback, repeatable benchmark |
| 70 | Timed original practice and exam-booking review | Readiness score and gap list |

**Certification rule:** Download the current official exam guides and verify training, voucher eligibility and exam availability with the company. These dates are suggested learning targets, not booked examinations.

# 八週後進階延伸：Data Engineer Professional 與 Context Engineer

原本八週著重 **Data Engineer Associate 和 GenAI Engineer Associate**。如果還要深入公司提供的 **Data Engineer Professional**，以及額外建議的 **Context Engineer Associate**，應再延長四週、每週約 15 小時。

**第 9–10 週：** Spark 查詢計畫、Shuffle／Skew、Streaming Checkpoint、CDC、Schema Evolution、Lakeflow Production Operations、Unity Catalog 安全、CI/CD 和故障演練，最後根據官方 Data Engineer Professional 考綱檢查能力。

**第 11–12 週：** Context Assembly、RAG、Search、Memory、MCP、資料治理、MLflow Evaluation、Prompt Injection、安全隔離與 Agent Reliability，對照 Context Engineer Associate 官方考綱。

每天的主題、Lab 和英文進度請參照上表；正式課內 Lesson 名稱依公司 Partner Academy 登入後顯示為準。這是延伸學習路線，不保證所有公司 Voucher 都涵蓋額外證書。
