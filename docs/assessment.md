# Assessment Rubric

Score each domain 0–4 (0 no evidence, 1 assisted, 2 working demo, 3 independently repeatable, 4 production-minded): Spark + Delta, Lakeflow pipelines, Governance, Performance, CI/CD, Retrieval, Agent Tooling, MLflow Evals, Secure Deployment, Client Architecture.

**Suggested success:** no domain below 3; pass a failure-injection drill; attach reproducible test evidence. This is independent rubric, not an official exam threshold. The 85% self-test target is a personal practice threshold only.

# 驗收標準

以 0–4 分評估：Spark/Delta、Lakeflow、Unity Catalog、效能、CI/CD、RAG、Agent Tools、MLflow Evaluation、安全部署及客戶架構。

**建議通過：** 各項至少 3 分，完成故障注入演練並提交可重現測試。這不是官方認證分數；85% 是自行設定的模擬考目標。
