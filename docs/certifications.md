# Certification Roadmap

**Priority:** (1) [Data Engineer Associate](https://www.databricks.com/learn/certification/data-engineer-associate), (2) [Generative AI Engineer Associate](https://www.databricks.com/learn/training/certification), (3) Context Engineer Associate, (4) AWS Platform Architect Accreditation, (5) Data Engineer Professional. Use [Databricks official certification catalog](https://www.databricks.com/learn/training/certification) for exact exam guides and availability.

The first three were mentioned in the Accenture internal post: Data Engineer Associate, Data Engineer Professional, and Generative AI Engineering certification. The other paths are recommendations, **not** confirmed company-voucher entitlements.

### Internal process from provided screenshot

1. Register courses/certification in **Workday**.
2. Use your **Accenture email** to create a Databricks Partner Academy account.
3. Request hands-on **Co-Lab access** using the internal request form.
4. After training, collect **completion certificate + screenshot of Workday enrollment**.
5. Submit both via the internal **Databricks Certification Voucher Request Form**.

Internal form URLs are **not** included because they were not present as accessible URLs. Obtain them from the company's original post. Verify exam booking, voucher availability and expiry independently. Certification dates in this plan are readiness targets, not confirmed appointments.

# 認證與官方學習路線

**優先順序：**（1）Data Engineer Associate、（2）Generative AI Engineer Associate、（3）Context Engineer Associate、（4）AWS Platform Architect Accreditation、（5）Data Engineer Professional。請以[官方認證目錄](https://www.databricks.com/learn/training/certification)與最新 Exam Guide 為準。

Accenture 截圖列出的三張是 Data Engineer Associate、Data Engineer Professional、Generative AI Engineering Certification。額外認證是學習建議，**不能假設公司會提供 Voucher**。

### 公司內部程序（根據截圖）

1. 在 **Workday** 登記要考的證照。
2. 使用 **Accenture 信箱**申請 Databricks Partner Academy。
3. 透過內部 **Co-Lab Access Request Form** 申請實驗環境。
4. 完成課程，準備**完課證明及 Workday 登記截圖**。
5. 使用內部 **Certification Voucher Request Form** 申請考試憑證。

截圖未提供可直接辨識的內部 URL，因此不猜測連結。課表中的應考日期只是準備度目標，不代表已預約。
