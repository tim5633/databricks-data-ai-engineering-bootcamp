### Public verified example of exact official sections

[**Data Analysis with Databricks**](https://partner-academy.databricks.com/learn/courses/830/data-analysis-with-databricks-sql-ilt) publicly lists two course sections:
1. **SQL Analytics on Databricks:** Data Discovery → Data Importing → SQL Execution → Query Analysis. Labs include Unity Catalog dataset discovery, ingestion, SQL transforms, and Query Insights.
2. **AI/BI for Data Analysts:** Dashboard foundations → curated SQL datasets → multi-page visualizations and filters → Genie assistance → publishing.

These are **verified publicly visible section headings**. For the other screenshot courses, links are to the [official learning catalog](https://www.databricks.com/learn/training/home) and your corporate [Partner Academy](https://partner-academy.databricks.com/); their exact gated lesson-by-lesson list has not been inspected. The mapped topics are practical daily targets, **not claims of 100% verified internal lesson completion**.

## Employer registration and voucher process

1. Day 01: Create account using **Accenture email**, submit **Co-Lab Access Request** through the original internal form and enroll in intended certifications via **Workday**.
2. Once trained: retain completion evidence and Workday enrollment screenshot **privately**, not in this public repo.
3. Submit those documents via employer's **Databricks Certification Voucher Request Form**.
4. Book the examination through official delivery channel once ready. Extra certifications/vouchers must be verified separately.

See [certification and employer process](certifications.md).
